A tiny Python program that writes one hilarious line to `/output/entry.txt`:
a robot vacuum that keeps ramming the same chair leg, fired from cleaning
and rehired as a grief counselor for the furniture.

Run it with `python3 main.py`. It writes `entry.txt` into the directory
named by `MAKEFUN_OUTPUT_DIR`, or `/output` by default. The output is
deterministic: every run writes the exact same bytes.
